# ClipDedup v0.2.0

> 去重逻辑升级为「完全去重」。

一句话定位：本版本把去重范围从「上一条」扩展到「最近 100 条复制历史」，隔条重复复制也会被拦截；提供 Windows 10/11 x64 免安装单文件。

## 系统支持范围

**支持的操作系统：Windows 10 与 Windows 11。**

| 系统 | 架构 | 支持情况 |
| --- | --- | --- |
| Windows 10 / 11 | x64（64 位） | 支持 |
| Windows 10 / 11 | ARM64 | 未提供预编译包：可自行 `cargo build --release`（需要 aarch64-pc-windows-msvc 工具链） |
| Windows 10 / 11 | x86（32 位） | 不提供 |
| Windows 7 / 8 | — | 不支持 |

## 下载

| 文件 | 适用 |

**Windows**：双击运行即可，程序在系统托盘中驻留，无主窗口。右键托盘图标可操作菜单。

## 本版本更新

### 新增

- 「完全去重」：新复制内容与最近 100 条复制历史中任意一条重复即被拦截，中间复制过其他内容不影响判断（例：复制 A → 复制 B → 再复制 A，第二次 A 会被拦截）。
- 托盘菜单新增「清除去重历史」，可一键清空比对历史。
- 托盘提示显示当前历史条数（`ClipDedup · 完全去重运行中（历史 N 条）`）。

### 修复

- 无。

### 变更

- 去重比对范围由「上一条内容」改为「最近 100 条历史」（FIFO，超出容量淘汰最旧一条）。
- 重新启用去重时，当前剪贴板内容会记入历史：再复制它同样会被拦截。

## 已知问题

- 去重只针对文本内容；图片、文件等非文本复制不做比对，直接放行。
- 拦截通过清空剪贴板实现（约 120ms 内完成），期间复制的内容不会停留在剪贴板。
- 拦截反馈通过托盘 tooltip 展示（悬停托盘图标可见），无弹窗通知。
