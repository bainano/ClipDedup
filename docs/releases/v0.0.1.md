# ClipDedup v0.0.1

> 首个正式版本：完全去重 + 系统通知 + 新图标。

一句话定位：首个版本，提供 Windows 10/11 x64 免安装单文件，持续监听剪贴板、拦截重复复制并弹出系统通知。

## 系统支持范围

**支持的操作系统：Windows 10 与 Windows 11。**

| 系统 | 架构 | 支持情况 |
| --- | --- | --- |
| Windows 10 / 11 | x64（64 位） | 支持 |
| Windows 10 / 11 | ARM64 | 未提供预编译包：需自行安装 aarch64-pc-windows-msvc 工具链后 `cargo build --release` |
| Windows 10 / 11 | x86（32 位） | 不提供 |
| Windows 7 / 8 | — | 不支持 |

## 下载

| 文件 | 适用 |
| --- | --- |
| `ClipDedup-0.0.1-win-x64.exe` | Windows 10/11 x64 免安装单文件 |

> 文件名使用 ASCII：GitHub Release 的上传接口会剥离资产名中的非 ASCII 字符。

**Windows**：双击运行即可，程序在系统托盘中驻留，无主窗口，也不会弹出控制台窗口。右键托盘图标可打开菜单。

## 本版本更新

### 新增

- 完全去重：新复制内容与最近 10 条复制历史中任意一条重复即被拦截（中间复制过其他内容同样生效），重复内容会被立即清空，不会停留在使用者的剪贴板里。
- 系统通知：拦截到重复复制时弹出系统通知「已帮你拦截一条重复复制」，托盘菜单「系统通知」可随时开关。
- 托盘菜单新增「清除去重历史」，一键清空比对历史。
- 采用新的应用图标：托盘图标取自 `assets/icon.png`，exe 文件图标由 `assets/icon.ico` 在构建时嵌入。

### 修复

- 无（首个版本）。

### 变更

- 去重历史容量由 100 条缩减为 10 条：用户通常只因较早的内容找不到才重新复制，过大的比对范围没有实际意义。
- 移除控制台窗口：始终以 Windows 子系统构建，双击启动不再出现黑色终端窗口。

## 已知问题

- 去重只针对文本内容；图片、文件等非文本复制不做比对，直接放行。
- 拦截在约 120ms 内完成，重复内容在该窗口期后才被清除；期间若使用需要长时间占用剪贴板的程序，可能出现短暂读写冲突（重试机制已覆盖绝大多数情况）。
- 系统通知依赖 Windows 通知服务：若系统关闭了该程序的通知或开启了专注助手，通知不会弹出（不影响去重本身）。
