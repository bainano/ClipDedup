# ClipDedup v0.1.0

> Windows 剪贴板去重托盘小工具首个版本。

一句话定位：首个版本，提供 Windows 10/11 x64 免安装单文件，持续监听剪贴板并拦截连续重复复制。

## 系统支持范围

**支持的操作系统：Windows 10 与 Windows 11。**

| 系统 | 架构 | 支持情况 |
| --- | --- | --- |
| Windows 10 / 11 | x64（64 位） | 支持 |
| Windows 10 / 11 | ARM64 | 未提供预编译包：可自行 `cargo build --release`（需要 aarch64-pc-windows-msvc 工具链） |
| Windows 10 / 11 | x86（32 位） | 不提供 |
| Windows 7 / 8 | — | 不支持 |

## 下载

| 文件 | 适用 |
| --- | --- |
| `ClipDedup-0.1.0-win-x64.exe` | Windows 10/11 x64 免安装单文件 |

> 文件名使用 ASCII：GitHub Release 的上传接口会剥离资产名中的非 ASCII 字符。

**Windows**：双击运行即可，程序在系统托盘中驻留，无主窗口。右键托盘图标可操作菜单。

## 本版本更新

### 新增

- 持续监听系统剪贴板（120ms 轮询剪贴板序号），检测每一次复制动作。
- 重复复制拦截：新复制内容与上一条完全相同时，立即清空剪贴板，使本次重复复制不生效，并通过托盘提示累计拦截次数。
- 系统托盘图标驻留，右键菜单：启用去重（暂停/恢复）、开机自启动开关、退出。
- 开机自启动：写入/删除 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，无需管理员权限。

### 修复

- 无（首个版本）。

### 变更

- 无（首个版本）。

## 已知问题

- 去重只针对文本内容；图片、文件等非文本复制不做比对，直接放行。
- 拦截反馈通过托盘 tooltip 展示（悬停托盘图标可见），无弹窗通知。
- 暂停去重后重新启用时，以当前剪贴板内容为新基线，重新启用后的第一次重复复制不会被拦截。
